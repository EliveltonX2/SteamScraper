O sistema está implementado de acordo com as especificações exigidas.
Certifique-se de executar com `streamlit run app.py` localmente.
Para hospedagem no Streamlit Community Cloud:
1. Suba os arquivos `app.py` e `requirements.txt` em um repositório no seu GitHub.
2. Acesse share.streamlit.io e crie uma nova aplicação vinculada ao seu repositório.
3. Não requer configurações adicionais, pois o requirements.txt já listará todas as bibliotecas.
